# Siemens Lab Envanter Yönetim Sistemi

Bu proje, Siemens laboratuvarındaki ekipmanların dijital ortamda takibini sağlamak amacıyla geliştirilmiş bir web uygulamasıdır.

## Kullanılan Teknolojiler
* **Frontend:** HTML5, CSS3, JavaScript

##  Projenin Amacı
Laboratuvardaki ekipmanların giriş-çıkış süreçlerini hızlandırmak, manuel yönetim sürecini modernize etmek ve dijital envanter altyapısı kurmaktır.
